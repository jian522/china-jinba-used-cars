# 金霸每日上架 · 标准提示词

> 用途：手动触发每日上架时，把下面这段直接发给 WorkBuddy 即可；定时任务每天 09:30 也会自动执行同样的流程。

## 提示词（复制以下全部内容）

```
@skill:jinba-car-pipeline 执行今日自动上架：

1. 运行编排脚本（全自动，无需逐步确认）：
   "C:/Users/Administrator/AppData/Local/Programs/Python/Python312/python.exe" D:/二手车出口网站/scripts/daily_upload.py
   （可选参数：--count 3 或 --count 5 调整台数，默认 4 台）

2. 脚本自动完成：车型池轮换选车（20 款热销车型，约 5 天一轮）→ wap.che168.com 采集实拍图与参数 → 入库（stock_id 自动避让现有号段）→ photo_fix 修水印条/换内饰封面 → 缩略图 → build_v2 构建四语页面 → photo_check 图片合规校验 + validate_inventory 数据校验 → git commit → push_api 部署 → IndexNow。

3. 部署后验收：
   - photo_check 违规 = 0 台
   - validate_inventory 错误 = 0
   - curl 抽查新车页 https://jinbacars.com/zh/cars/<数字id>/ 返回 200（注意是目录式 URL，不是 JB-编号.html）

4. 汇报：上架台数、stock_id 与车型对照、部署提交号、线上验证结果。任何校验不过就不部署，报告原因。
```

## 关键备忘

| 项目 | 约定 |
|------|------|
| Python 解释器 | 必须用 Python312（内置 3.13 缺 requests/Pillow） |
| 采集通道 | wap.che168.com（m.che168.com 被 EdgeOne 拦截） |
| 每日台数 | 3~5 台，默认 4 |
| 车型池 | 哈弗H6/大狗/初恋、坦克300、长城炮、宋PLUS/元PLUS/海豚/海鸥/汉/海豹/秦PLUS、理想L6/L7、问界M7、CS75 PLUS、瑞虎7/8、博越L、星越L |
| 图片规则 | 背景干净无 logo/水印；封面须正前或左前 45°；内饰/车尾不得作封面 |
| 页面 URL | `https://jinbacars.com/zh/cars/<数字id>/`（如 327/ 对应 JB-9000） |
| 定时任务 | WorkBuddy 自动化：每天 09:30（ID 1f1ced0f-bb55-4f77-b15c-af1cb01491a5） |
