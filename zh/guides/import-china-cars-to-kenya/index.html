对肯尼亚车商而言，中国二手车——尤其是比亚迪二手电车——是增长最快的进口品类之一。本指南拆解FOB深圳与CIF蒙巴萨的真实成本结构、你必须收到的出口单证，以及付款前如何核实经过检测的车源。

FOB深圳与CIF蒙巴萨：各包含什么。FOB涵盖车辆、168项装运前检测、中国出口报关以及蛇口/盐田装船。海运费、海运保险与肯尼亚进口税费由你安排。CIF蒙巴萨把运费与保险合并成一个报价——是规划落地成本最简单的方式——而关税（按车龄与价值浮动）、IDF、RDL规费与蒙巴萨港杂费在任何条款下都不在报价内。

出口单证清单。清关行需要：提单（正本或海运单）、商业发票与装箱单、出口报关单，以及KEBS装运前符合性验证要求的检验证书（COI）。电动车另附符合UN 3480海运规则的电池处理文件。

168项装运前检测：查什么。结构件与事故史、对照保养记录核验里程表、电动车电池健康度测试、机械与电子功能、内外观车况并附带日期的照片集。装柜前欢迎在深圳委派独立验车人。

整柜拼装发运。40尺柜装4–6台SUV或8–10台紧凑车。多数肯尼亚车商混装2–4台比亚迪电车与2–4台汽油SUV，同时覆盖内罗毕等城市买家与内地零售。整柜分摊运费通常比零担拼货节省30–45%的单车运输成本。

首次进口者的付款安全。只向签约公司账户付款，坚持索取注明库存编号的书面报价，遇到临时更换收款方立即停手。常规节奏：30%定金锁车，见提单副本付70%尾款。

典型时间线。当天报价 → 定金锁车 → 检测与装柜（3–7天）→ 蛇口开航 → 海上25–32天 → 蒙巴萨卸货清关。欢迎索取本周CIF蒙巴萨费率表——它随海运行情波动。
